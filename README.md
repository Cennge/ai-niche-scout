# AI Niche Scout

Validate an AI startup idea: find competitors and explore 54 AI niches, powered by the [FreeSerp](https://freeserp.ai) sites index.

> Work in progress. See [PLAN.md](PLAN.md) for the site plan: goal, audience, pages and structure.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
